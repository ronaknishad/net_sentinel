# Datasets

Large datasets are not stored in Git. Place downloaded CSV files here.

## Primary dataset: CIC-IDS2017 (not bundled)
Source: Canadian Institute for Cybersecurity, University of New Brunswick. The "MachineLearningCSV"
download is roughly 200+ MB across 8 CSV files, so it is NOT downloaded automatically.
Check the CIC website for current licence and citation terms before using or redistributing it.
Start with one day's file (for example the Friday DDoS or PortScan file) to keep training fast.

Expected format: one flow per row, CICFlowMeter column names, a `Label` column. The import
validator maps header variants automatically and reports any column it cannot use.

## Bundled demonstration data
`ml/data/sample_synthetic_flows.csv` is SYNTHETIC (generated by `ml/synthetic.py`). It exists so the
workflow and tests run offline. It is not real traffic and must never be reported as benchmark data.

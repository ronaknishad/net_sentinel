# Demonstration Procedure (Windows)

## One-time setup
```powershell
cd netsentinel
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r backend\requirements.txt
cd frontend
npm install
cd ..
```
(`scripts\setup.ps1` runs the same steps.)

## Start the application
Terminal 1 (project root, virtual environment active):
```powershell
python -m uvicorn backend.app.main:app --port 8000
```
Terminal 2:
```powershell
cd frontend
npm run dev
```
Open http://localhost:5173. The top bar shows **No model loaded** until a model is trained.

## Walkthrough
1. **Network Overview** shows the empty state: "No analysis available yet. Import a network traffic CSV to begin."
2. **Dataset Management** -> *Load bundled synthetic sample*. Review the validation report: 3,015 rows,
   a `Label` column, mapped features, columns not used (Flow ID, Source IP, Source Port, Timestamp), duplicates, class distribution.
3. Choose **Multiclass**, tick the confirmation, press **Train model**. A progress notice appears; on completion the top bar changes to
   *Model loaded: Random Forest (multiclass)*.
4. **Model Evaluation**: a banner states the data is synthetic. Review the metrics, the confusion matrix, per-class results and the
   model comparison. Download the CSV or JSON report.
5. Back in **Dataset Management** press **Analyse selected dataset**. The message reports records processed and records classified as suspicious.
6. **Network Overview** now shows the totals, class chart and timeline (the synthetic data has timestamps).
7. **Traffic Analysis**: filter *Classification = Suspicious*, sort by confidence, open a row to see its features, prediction and alert.
   Export the analysis CSV.
8. **Detection Alerts**: High severity alerts are listed first. Change one alert to *Under review*, restart the backend, and confirm the status persists.

## Normal flow and suspicious flow
In **Traffic Analysis**, scroll to *Classify a single flow*:
- Press **Load synthetic Normal**, then **Classify flow**: expected prediction *Normal*.
- Press **Load synthetic DoS**, then **Classify flow**: expected prediction *Suspicious: DoS* with High severity (multiclass model).
  Tick *Save as an analysis* to create an alert.
- Edit the JSON to remove a field and classify again: the API rejects it and names the missing feature.

Also try **Load synthetic Brute Force**. On the example run this sample is classified as *Normal* (confidence about 0.84),
a genuine missed detection: the generator gives Brute Force flows some benign-like parameters, and the model treats
this one as normal. It is a useful way to discuss recall and why a prediction is only a lead.
Expected results on the bundled sample with a freshly trained Random Forest:

| Synthetic sample | Multiclass prediction | Binary prediction |
|------------------|-----------------------|-------------------|
| Normal | Normal | Normal |
| DoS | DoS (High) | Suspicious (Medium) |
| PortScan | PortScan (Medium) | Suspicious (Medium) |
| Brute Force | Normal (missed) | Normal (missed) |

These samples are synthetic and generated by documented rules. A different trained model or library version may classify them differently.
